# Criaturas-de-RPG
Um aplicativo web que usa a "rpg-creature-api" da freeCodeCamp para buscar informações de diferentes criaturas de RPG e mostrar suas estatísticas para o usuário. Este projeto foi desenvolvido como uma solução para o desafio de certificação "Build an RPG Creature Search App" do curso "JavaScript Algorithms and Data Structures" da freeCodeCamp.

Para buscar dados das criaturas no aplicativo, o usuário poderá inserir o nome ou o ID da criatura no campo de pesquisa. Uma lista completa de todas as criaturas está disponível em: "https://rpg-creature-api.freecodecamp.rocks/".
